# Автоматизация тестирования мобильного приложения

5 автотестов для проверки авторизации.

## 🛠 Стек технологий
*   Java 11+
*   Appium (java-client 10.1.1)
*   JUnit 5
*   AssertJ (Soft Assertions)
*   Allure Report

## 🏗 Архитектура проекта
Проект реализован с использованием паттернов **Page Object**, **Factory** и **Fluent Interface**.
*   `pages/` — Page Object классы.
*   `locators/` — Интерфейсы и реализации локаторов (готово к поддержке iOS).
*   `steps/` — Бизнес-шаги с атомарной разметкой `@Step` для Allure.
*   `checks/` — Слой проверок (Hard и Soft ассерты).
*   `extensions/` — Кастомный `AfterTestExecutionCallback` для создания скриншотов при падении тестов.

## 🚀 Как запустить
1. Установите и запустите Appium Server: `appium`
2. Запустите эмулятор Android (устройство `emulator-5554`).
3. Выполните: `./gradlew test`
4. Для генерации отчета: `./gradlew allureServe`

## ✅ Покрытые сценарии (5 автотестов)
1. Успешный вход (А.01.01).
2. Вход с невалидными данными (А.01.02, параметризованный).
3. Проверка маскировки пароля (А.01.03).
4. Ввод и вставка неразрешенных символов в логин/пароль (А.01.04).
5. Проверка лимита ввода — 50 символов (А.01.05).

## 📸 Отчеты
Фреймворк настроен на автоматическое создание скриншотов при падении тестов.
